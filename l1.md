# Część I – Wprowadzenie do terminala (10 min)

## 3. Czym jest Bash?

Bash (Bourne Again Shell) to powłoka systemowa umożliwiająca komunikację z systemem operacyjnym za pomocą poleceń tekstowych.

Terminal jest programem, w którym możemy uruchamiać powłokę i wpisywać polecenia.

Bash pozwala między innymi:

- zarządzać plikami i katalogami;
- uruchamiać programy;
- automatyzować powtarzalne zadania;
- tworzyć skrypty;
- zarządzać systemem operacyjnym.

### Zadanie 1 – Poznajemy terminal

Wykonaj poniższe polecenia:

```bash
pwd
ls
ls -la
whoami
date
uname -a
```

Odpowiedz na pytania:

1. Co pokazuje polecenie `pwd`?
2. Czym różni się `ls` od `ls -la`?
3. Jak sprawdzić nazwę aktualnego użytkownika?
4. Co wyświetla polecenie `uname -a`?
5. Jak sprawdzić aktualną datę i godzinę?

Wykonaj następujące operacje:

# Część IV – Pierwszy skrypt Bash (20 min)

## 6. Czym jest skrypt?

Skrypt Bash to zwykły plik tekstowy zawierający polecenia, które Bash wykonuje kolejno.

Skrypty najczęściej zapisujemy z rozszerzeniem `.sh`.

### Zadanie 5 – Hello World

Utwórz plik `hello.sh`:

```bash
#!/bin/bash

echo "Witaj w świecie Bash!"

echo "Aktualna data:"
date

echo "Zalogowany użytkownik:"
whoami
```

Uruchom skrypt:

```bash
chmod +x hello.sh
./hello.sh
```

Odpowiedz:

1. Co oznacza `#!/bin/bash`?
2. Do czego służy `chmod +x`?
3. Dlaczego używamy `./hello.sh`?
4. Czy można uruchomić skrypt bez nadawania mu prawa wykonywania?

### Zadanie 6 – Zmienne

Zmienne pozwalają przechowywać dane, które można później wykorzystywać w skrypcie.


# Część V – Instrukcje warunkowe i pętle (15 min)

## 7. Instrukcje warunkowe

Instrukcja `if` pozwala wykonywać różne polecenia w zależności od spełnienia warunku.

Przykład:

```bash
#!/bin/bash

liczba=10

if [ "$liczba" -gt 0 ]; then
    echo "Liczba dodatnia"
else
    echo "Liczba niedodatnia"
fi
```

Przydatne operatory:

| Operator | Znaczenie |
|---|---|
| `-eq` | Równe |
| `-ne` | Różne |
| `-gt` | Większe |
| `-lt` | Mniejsze |
| `-ge` | Większe lub równe |
| `-le` | Mniejsze lub równe |

### Zadanie 8 – Sprawdzanie liczby

2. Sprawdza, czy liczba jest dodatnia.
3. Sprawdza, czy liczba jest ujemna.
4. Informuje, czy liczba jest równa zero.

## 8. Pętle

Pętle pozwalają wielokrotnie wykonywać te same instrukcje.

Przykład:

```bash
#!/bin/bash

for i in {1..10}
do
    echo "$i"
done
```

Temat następnych zajęć: Argumenty skryptów, funkcje, potoki, uprawnienia plików i automatyzacja zadań w Bash.

**Inne skrypty**

- Sortowanie
```bash
#!/bin/bash

SOURCE="$HOME/Downloads"

mkdir -p "$SOURCE/Dokumenty"
mkdir -p "$SOURCE/Obrazy"
mkdir -p "$SOURCE/Archiwa"

for file in "$SOURCE"/*; do
    [ -f "$file" ] || continue

    case "${file##*.}" in
        pdf|docx|txt)
            mv -- "$file" "$SOURCE/Dokumenty/"
            ;;
        jpg|jpeg|png)
            mv -- "$file" "$SOURCE/Obrazy/"
            ;;
        zip|tar|gz)
            mv -- "$file" "$SOURCE/Archiwa/"
            ;;
    esac
done

echo "Porządkowanie zakończone!"
```

- Kopie zapasowe
```bash
#!/bin/bash

SOURCE="$HOME/Documents"
DEST="$HOME/Backup"

DATE=$(date +"%Y-%m-%d_%H-%M-%S")

mkdir -p "$DEST"

tar -czf "$DEST/backup_$DATE.tar.gz" "$SOURCE"

echo "Kopia zapasowa została utworzona!"
echo "Plik: backup_$DATE.tar.gz"
```
